## 关键业务语义保护

- 人工 BOM 调整不会被推荐流程覆盖。
- 每次保存创建不可变 BOM 新版本；验收项目产生 V1、V2、V3。
- 项目单价只作用于当前项目，不修改产品中心参考价格。
- `Project.status` 继续作为项目生命周期单一状态源。
- 文档发布、当前有效、AI 知识状态仍由真实后端字段决定，前端只中文化呈现。
- 六大中心、LDAP、Dify、后端模型和既有业务范围未重构。
