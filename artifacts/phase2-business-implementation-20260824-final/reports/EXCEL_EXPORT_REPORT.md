# Excel 模板与导出报告

## 模板能力

- 占位符模板：支持项目、客户、地区、版本、日期、制表人、总价等占位符。
- 普通模板：支持多 Sheet 可视化预览和单元格点击映射。
- BOM 行映射：行号、产品名称、型号、数量、单位、项目单价、小计、用途、备注。
- 保留模板 Logo、合并单元格、冻结窗格、列宽、样式和公式。

## 正式模板

- id 1：占位符模板
- id 2：首个普通模板
- id 3：改进后的标准普通模板，扩大项目名称和客户字段宽度
