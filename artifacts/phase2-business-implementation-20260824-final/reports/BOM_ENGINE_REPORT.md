# BOM 引擎报告

## 能力

- 自然语言需求解析与结构化确认
- 产品、型号、能力、场景和方案的真实关系推荐
- 规则版本、优先级、严重级别、生效状态和审计
- 人工修改优先；规则重算不覆盖 `manualEdited=true` 项
- BOM 校验 PASS/WARNING/ERROR 与管理员覆盖审计
- 每次保存形成不可变 BOM 版本

## 验收场景

输入：桥梁上下游各 3 公里、4 个球机、AIS 融合、船名 OCR、偏航预警、7x24 小时运行。

结果：

- 上游距离：3 公里
- 下游距离：3 公里
- 真实产品 BOM：3 条
- 人工调整：首条数量 1 改为 2
- 人工备注：`人工调整：主平台双机冗余`
- 校验：3 PASS / 0 WARNING / 0 ERROR
- 项目：`桥梁防撞业务验收项目-20260824`，id 6
- 版本：V2、V3 均标记人工调整；V3 为当前版本

## 安全

普通用户无项目/BOM 访问；销售和产品经理按权限访问；价格字段仅对 `PRICE_VIEW` 返回。销售不能覆盖 ERROR，管理员覆盖必须记录原因和操作者。
